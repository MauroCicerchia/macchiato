# Security policy

macchiato is a small shell wrapper, but it runs in your terminal and starts `caffeinate`. If you find a way to make it run unexpected commands, leak data, or leave `caffeinate` running after it exits, please report it privately.

Use GitHub's [private vulnerability reporting](https://github.com/MauroCicerchia/macchiato/security/advisories/new) instead of a public issue. Expect a first reply within a week.

Only the latest release is supported.
